# Why the base has no front end

The planner asks for overdue work, records a reading and prepares the weekly pack through a coding agent and one CLI. The database is the product. Read-only HTML snapshots show the same records without a running web application.

MEX offers mobile and offline workflows, forms, notifications, integrations and permissions. This base does not implement those experiences. A screen supports field capture, pictures, scanning, drag-and-drop scheduling and offline work that text commands and generated snapshots do not provide. Existing attachments are referenced rather than uploaded.

Enterprise DNA builds the agreed field experience, connections and approval process into a custom version. The free base is for an administrator or planner with controlled database access. It is not a replacement for an on-site safety system, physical isolation or a competent inspection. Multi-user hosting requires an access model, backups and operating procedures.

Omni by Enterprise DNA installs and runs the agreed version for one setup fee, then a retainer.
